# Tells and what replaces them

These are the defaults generated pages fall into. None of them is wrong in itself: linear.app ships
six of them and still looks expensive. They're tells when they appear *by default*, regardless of
subject, at default calibration. Read this file during critique, not while planning. Planning works
from the reference and the inventory, never from this list.

For each tell: if DESIGN.md justifies it from the reference or the subject, keep it. If not, make the
replacement move.

Tier 1 is the original generated look. Tier 2 is what models fall into once tier 1 is banned. If you
avoid both and land on something that feels like the "next" safe choice, you have found tier 3. The
way out is always the subject and the reference, never another ban.

## Tier 1

| Tell | Replacement move |
| --- | --- |
| Indigo or purple gradient, or gradient text | A flat accent taken from the subject or the reference, used on the action only |
| Inter, Roboto or system font with no tuning | The reference's families, or a face chosen for the subject. If Inter, tune it: tracking per size and a non-default weight |
| Tailwind slate or zinc greys untouched | An ink staircase measured from the reference, with tinted neutrals |
| Centred hero, pill badge, two buttons, screenshot below | A composition from the idea sentence. One action, and left alignment unless the idea needs centre |
| Row of three identical icon cards | Content set at different weights: one item leads, the rest list. Or a real fragment of the product |
| Rounded icon tile above every heading | No icon. The heading carries it |
| One radius and the same soft shadow on everything | A radius rule decided by hierarchy. Separate with tone steps; shadows only on floating things |
| Glass panels, backdrop blur, floating pill nav | A plain bar: wordmark, 3–5 links, one action |
| Decorative blobs, orbs, grid backgrounds | Scale, a field of flat colour, or a real picture of the subject's world |
| Emoji as icons | Words, or one consistent icon set at one stroke weight |
| Stock section order: hero, logos, features, stats, pricing, CTA, four-column footer | Sections that follow the argument. Every section has a claim. The footer is a designed close |
| "Elevate", "seamless", "unlock", "powerful"; "Get started" | Specific claims about this subject, and verb + noun actions |
| Same fade-and-rise on every section; hover lift on every card | One orchestrated moment, plus feedback on controls |
| Muted grey body text below 4.5:1 | Body in the first or second ink |

## Tier 2

| Tell | Replacement move |
| --- | --- |
| Warm cream (~#F4F1EA) + high-contrast serif + terracotta (~#D97757) | Colours from the subject's own materials or the reference profile |
| Near-black (#0B0B0B / #111) with one acid-green or vermilion accent | If dark, take the grounds and accent from a measured dark reference |
| Instrument Serif, Fraunces, Space Grotesk, Geist as "the tasteful choice" | A face chosen for this subject's vernacular, or the reference's |
| One italic, coloured or underlined word in the headline | Let the words carry the emphasis. Spend boldness on scale or placement |
| Tracked ALL-CAPS eyebrow above every heading | Put the information in the heading or the first sentence, in sentence case |
| Monospace for small labels and meta | The text face with `tabular-nums` |
| `A · B · C` meta strings, `WORD — fragment` labels, `→` on every link | Plain labels. An arrow only where something really moves forward |
| 01 / 02 / 03 numbering on content that isn't a sequence | Order by position or size. Use a real `<ol>` when it is a sequence |
| Broadsheet hairlines, zero radius, dense newspaper columns | Space and tone steps for structure. Hairlines only where the reference uses them, at its alpha |
| Big number + small label + stats row as the hero | The subject's most characteristic thing, at full scale |
| Status-chip soup, pulsing "live" dots | One status shown as text and colour where it matters |
| Fake window chrome (macOS dots) around screenshots | The real interface, cropped with intent |

## Copy-level smells (any tier)

- A headline that would work for a competitor.
- Three adjectives in a row.
- "Lorem ipsum", "John Doe", "Acme", "Item 1".
- Invented testimonials, logos or metrics.
