ICEX Next

Application portal, at Humannova

Sep 2026 – now

See the sign-in

Every privacy acceptance is stored with the version of the policy and the date it was accepted, and questionnaire drafts survive new versions of the questionnaire.

An application portal for the ICEX Next programme, cut down from Reskillia to what the client needed: no AI, no public sign-up, privacy first. The team invites each person, who sets a password, accepts the policy and submits a CV, read from PDF or image with local OCR for scanned documents. Answers export to Excel for the reviewers.

Next.js 16, React 19, Tailwind CSS 4, Supabase, Docker

Reskillia

AI skills assessment, at Humannova

Mar 2026 – now

Visit Reskillia

Personal data is encrypted with AES-256-GCM before it reaches PostgreSQL, and row-level security decides who can read each row.

Companies assess their team’s digital skills against DigComp 2.2, the European framework. Each person uploads a CV; Gemini picks seven competences with a target level, writes the questions and scores the answers. The result is a radar of expected against achieved, as a PDF. In Spanish and Catalan.

Next.js 16, React 19, Supabase, Gemini, Docker

CPU City

Explorable processor, personal

Oct 2026

Open CPU CityCode

RISC-V assembly runs in a Web Worker, and every instruction can be followed down to the ALU circuit that executes it.

Tomate

macOS study timer, personal

Oct 2026

usetomate.comCode

Time is stored as dates, not as a countdown, so a session stays exact even when the Mac goes to sleep.

A Pomodoro timer for long study sessions, from 25 to 90 minutes, that can split anything over an hour into two blocks. Scheduled sessions never overlap, and macOS Focus turns on while you study. Everything stays on the Mac: no accounts, no server.

db-doctor

Claude skill, personal

Oct 2026

Code

It finds the loop that silently fires 500 queries, and proves it with evidence before proposing the fix.

An audit of an app’s database layer: SQL that no index can serve, N+1 queries hidden in ORM code, indexes every write pays for and no read uses. It ranks findings by impact and returns a plan with SQL, risks and how to validate each change.

Python, PostgreSQL, MySQL, Laravel, Prisma, Supabase
